## About

m0rph1n3-GCv1 brings a game collection into a clean, focused interface. A dark theme, streamlined navigation, and a straightforward layout keep the experience modern without making it complicated.

Built for school, with a simple goal: make browsing and launching games feel effortless.

## Highlights

| Feature | What it brings |
| :--- | :--- |
| Modern, minimal UI | A polished dark interface without unnecessary clutter. |
| Large Game Collection | Browse a list of over 350+ games from a visual card-based catalog. |
| Search | Find titles in the catalog quickly. |
| Saved games | Keep selected games in a dedicated Saved section. |
| Import tools | Add supported game content through the interface. |
| Responsive layout | A layout that adapts to smaller screens. |
| Social links | Find the creator on GitHub, Instagram, and TikTok. |

## Getting started

1. Download the project files or clone this repository.
2. Keep the included files together.
3. Open `index.html` in your browser.

For local HTTP hosting, run this command from the project directory if Python 3 is installed:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

> Some games and imports may depend on external resources, browser permissions, or the hosting environment. Flash content also requires a compatible playback solution; the catalog alone does not guarantee every game will run.

## Design philosophy

- Sleek, not crowded. Give the games room to stand out.
- Modern, not complicated. Keep navigation clear and predictable.
- Simple by intention. Focus on the experience rather than visual noise.
